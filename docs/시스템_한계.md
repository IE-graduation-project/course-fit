# 시스템 한계 및 의식적 분리 사항

## 1. 시간표 충돌 제약 미구현

### 사유
- 시간표 정보가 학사 일정상 수강신청 직전(2~3주 전)에 공개됨
- 데모/평가 시점(2026-05)에 정확한 시간표 데이터 사전 확보 불가능

### 대안 검토
| 옵션 | 채택 여부 | 이유 |
|------|----------|------|
| 작년 시간표 사용 | ❌ | 정확성 보장 안 됨, "현실 데이터 기반" 주장 약함 |
| 가상 시간표 생성 | ❌ | 임의 데이터 의존 → 발표 임팩트 약화 |
| 사용자 입력 | ❌ | 자동화 수준 낮음 |
| **시간표 제약 제거** | ✅ | 다른 4개 제약으로 ILP 정당성 유지 |

### 영향 분석
**유지되는 ILP 제약 (4개)**
1. 학점 상하한
2. 선수과목
3. 학년 제한
4. 졸업요건 (영역별 min/max + 강제 선택)

**유지되는 핵심 contribution**
- 직무 적합도 ↔ 학생 역량 ↔ 과목 역량 3축 매핑
- Gap 기반 Score 정의
- 정규화된 비교 척도
- ILP 다중 제약 최적화 (4개 제약)

### 데이터 모델 보존
- `course.time_slots_raw`, `course.time_slots_int` 컬럼 유지
- 시간표 정보 확보 시 ALTER 없이 즉시 활용 가능
- ILP 코드에 시간표 제약 추가만 하면 동작

### 발표 시 방어 논리
> "시간표 충돌 제약은 학사 일정상 시간표 정보가 수강신청 직전에 공개되는 제약으로 인해 본 MVP에서 제외했다. 데이터 모델은 시간표 정보를 수용할 수 있도록 설계되어 있으며, 시간표 공개 시점에 즉시 동작 가능하다. 본 연구의 핵심 기여인 직무 적합도 기반 추천과 ILP의 다중 제약 최적화는 시간표 외 4개 제약(학점, 선수, 학년, 졸업요건)만으로도 충분히 입증된다."
