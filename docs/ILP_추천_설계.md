# ILP 추천 엔진 설계 (리서치)

> **이 문서의 목적**
> `recommender/ilp_solver.py`를 구현하기 전에, ILP 추천이 **어떤 제약조건을 가지고
> 어떤 수식으로 표현되는지**를 정리한 설계 명세. (박소연 요청 리서치 산출물)
>
> **한 줄 요약**: "학생이 목표 직무를 고르면, 해당 학기에 실제로 열리는 분반 중에서
> ① 직무 적합도를 최대화하고 ② 졸업에도 도움 되며 ③ 시간이 서로 겹치지 않는
> 수강 시간표를 자동으로 골라준다."

---

## 0. ILP가 뭔지 (비기술 설명)

> 발표·인수인계용 쉬운 설명. 식은 4장부터.

학교에 들을 수 있는 과목이 수백 개다. 이 중에서 "재무 분석가에 가장 잘 맞는 다음 학기
시간표"를 사람이 손으로 고르는 건 경우의 수가 너무 많아 불가능하다. 그래서 컴퓨터가
**규칙(졸업·학점·시간 충돌)을 모두 지키면서 목표(직무 적합)를 가장 잘 달성하는 조합**을
자동으로 찾게 한다. 이렇게 "규칙을 지키며 최선의 조합을 찾는 수학 도구"가 **ILP**다.

- **I**nteger(정수): 답이 "그 분반을 듣는다(1) / 안 듣는다(0)"처럼 딱 떨어진다. 0.7과목은 없다.
- **L**inear **P**rogramming(선형계획법): 규칙을 부등식으로 적고 그 안에서 최선값을 찾는다.

비유: **예산(학점) 안에서, 필수 항목(졸업요건)을 채우고, 서로 안 부딪히게(시간 충돌)
가장 만족도 높은 장바구니(직무 적합)를 담는 문제.**

---

## 1. 문제 정의 (입력 / 출력 / 범위)

| 구분 | 내용 |
|------|------|
| **입력** | (1) 학생의 현재 역량(이미 수강한 과목에서 산출), (2) 목표 직무 `J`, (3) 대상 학기 `term`(예: `2026-1`), (4) 이번 학기 희망 학점 범위 |
| **출력** | `term`에 개설된 분반 중 추천 **수강 분반 목록**(= 시간 충돌 없는 한 학기 시간표) |
| **범위(MVP)** | 현재 보유 데이터가 `2026-1` 시간표뿐이라 MVP는 `2026-1`로 검증. **단 학기는 입력 파라미터이므로 `2027-1` 등 다른 학기 데이터가 들어오면 그대로 동작해야 한다(하드코딩 금지).** |

---

## 2. 설계 원칙 (기술 부채 방지)

1. **학기는 입력 파라미터.** 코드 어디에도 `2026-1`을 박지 않는다.
   후보 분반은 `course_section.source_term == term` 필터로만 정한다.
2. **과목 카탈로그 ↔ 학기 분반 스냅샷 분리 유지.**
   - `course.csv`: 과목 단위 SOT(학점·영역·역량 매핑 기준) — 학기 불변
   - `course_section.csv`: 학기별 개설 분반·교원·시간표 스냅샷 — 학기마다 교체
   - 둘은 `course_id`로 조인한다.
3. **결정 단위는 "분반"이다.** 같은 과목도 분반마다 시간이 다르므로(예: `데이터사이언스`
   1반 `수89,금9` / 2반 `목789`), 시간 충돌을 다루려면 과목이 아니라 **분반**을 골라야 한다.
4. **시간 충돌·졸업 보너스의 강약은 가중치(λ)로 조절** → 정책 변경 시 코드 구조를 안 바꾼다.

|---|-----------|-----------|-----------|

| P3 | **학생 현재 역량 산출**: `recommender/student_competency.py` (기수강 과목 → 역량 누적) | 미구현 | 후속 |

### P1 상세 — 시간 슬롯 인코딩 규칙

`time_slots_raw` 표기를 (요일, 교시) 정수 슬롯 집합으로 변환한다.

- **요일 매핑**: `월=0, 화=1, 수=2, 목=3, 금=4, 토=5`
- **슬롯 ID**: `slot = 요일 * 16 + 교시` (16은 하루 최대 교시 여유값)
- **다중 블록**: 콤마로 분리. 예) `수89,금9` → 수[8,9] + 금[9]
- **두 자리 교시 파싱 주의**: `월91011`은 9·10·11교시다. 교시는 1~9는 한 자리,
  10~15는 `1`로 시작하는 두 자리. 단순 한 글자씩 끊으면 `9,1,0,1,1`로 오파싱되므로
  "`1` 다음에 `0~5`가 오면 두 자리로 묶는" 파서가 필요하다.
- **빈 값(28개 분반)**: 비대면/미정 등으로 시간표가 없는 분반 → 시간 충돌 제약에서 제외
  (어떤 슬롯도 점유하지 않음).

## 4. 기호 정의 (데이터 → 수식)

리서치의 핵심: **어떤 CSV 값이 어떤 기호가 되는가.**

### 집합

| 기호 | 의미 | 출처 |
|------|------|------|
| `C` | 대상 학기 `term`에 개설된 **과목** 집합 | `course_section` (source_term=term) |
| `S(c)` | 과목 `c`의 개설 **분반** 집합 | `course_section` |
| `K` | 역량 10개 | `competency.csv` |
| `G` | 학생 학과의 졸업요건 **영역** 집합 | `graduation_requirement` |
| `T` | 시간 **슬롯** 집합 (요일×교시 정수) | `time_slots_int` (P1 산출) |

### 파라미터 (상수)

| 기호 | 의미 | 출처 |
|------|------|------|
| `cr_c` | 과목 `c`의 학점 | `course.credit` |
| `w_{c,k}` | 과목 `c`가 역량 `k`에 기여하는 가중치 (Σₖ w = 1) | `course_competency.weight` |
| `ρ_{J,k}` | 목표 직무 `J`가 역량 `k`에 요구하는 수준 (0~1) — **직무 기준**(채용공고에서 도출) | `job_competency.required_level` |
| `σ_k` | 학생의 **현재** 역량 `k` 수준 (기수강 누적) | `student_competency.py` (P3) |
| `slots(c,s)` | 분반 `(c,s)`가 점유하는 시간 슬롯 집합 ⊆ `T` | `time_slots_int` (P1) |
| `a_c` | 과목 `c`의 졸업영역 (∈ `G`) | `course.area` |
| `need_g` | 학생이 영역 `g`에서 아직 더 필요한 학점 = max(0, `min_g` − 기수강학점_g) | `graduation_requirement` + 학생기록 |
| `B_lo, B_hi` | 이번 학기 등록 학점 하한·상한 (예: 12, 21) | 학생 입력 |

## 5. 결정변수

| 변수 | 정의 | 형 |
|------|------|----|
| `y_{c,s}` | 분반 `(c,s)`를 수강하면 1, 아니면 0 | **0/1 (이진)** |
| `x_c` | 과목 `c` 수강 여부 = Σ_{s∈S(c)} `y_{c,s}` (파생) | 0/1 |
| `cov_k` | 역량 `k`의 (요구수준 이하로 캡된) 달성치 | 연속, ≥0 |
| `grad_g` | 영역 `g`의 (잔여 필요량 이하로 캡된) 채운 학점 | 연속, ≥0 |

> `Σ_s y_{c,s} ≤ 1`(제약 C1)이 걸리므로 `x_c`는 자동으로 0 또는 1이 된다.

**파생 정의 — 수강 후 역량 달성치:**
```
attained_k = σ_k + Σ_{c∈C} ( w_{c,k} · x_c )
```

---

## 6. 목적함수

우리가 정한 우선순위: **① 직무 적합(1순위) + ② 졸업 진척(보조).**

```
maximize   Z = Σ_{k∈K} ( ρ_{J,k} · cov_k )   +   λ · Σ_{g∈G} ( grad_g / need_g )
                 └────────── 직무 적합 ──────────┘       └──── 졸업 진척(정규화) ────┘
```

- **두 항의 스케일을 맞춰라(중요).** 직무 항은 `ρ,cov ∈ [0,1]`이라 `O(역량 수)` 크기지만,
  졸업 학점 `grad_g`는 학점 단위(수십)라 그대로 더하면 졸업 항이 직무 항을 압도한다. 그래서
  졸업 항은 **잔여 필요량 대비 비율 `grad_g / need_g ∈ [0,1]`** 로 정규화해 항당 크기를 맞춘다.
- `λ`(예: 0.1): 정규화 후의 졸업 보너스 가중치. 작게 둬서 **직무 적합이 우선**, 동점일 때
  졸업에 도움 되는 과목을 선호. (정규화를 전제로 한 값 — §부록 A에서 실측 튜닝)
- **왜 "캡(cov_k ≤ ρ)"이 핵심인가:** 단순히 `max Σ attained_k`로 두면 솔버가 요구수준이
  가장 높은 역량 한 곳에만 과목을 몰아넣어 점수를 부풀린다. 달성치를 **요구수준에서 잘라
  (cap)** 더 채워도 점수가 안 오르게 하면, 솔버가 자연히 **여러 요구 역량에 골고루 분산**한다.
- **`ρ`-가중의 의미(캡과 상호보완):** cov에 `ρ_{J,k}`를 곱하므로 **요구수준이 높은 역량의 갭일수록
  더 크게 줄이도록** 우선순위가 매겨진다. 즉 캡은 "한 역량 과투자 방지(균형)", ρ-가중은 "직무가
  더 요구하는 역량 우선"을 동시에 건다 — 상충이 아니라 보완이다.
- **"갭 최소화와 동치"는 정확히 ρ-가중 동치다.** 일반식 `max Σ_k w_k·cov_k ⇔ min Σ_k w_k·gap_k`
  (gap_k=ρ_k−cov_k, 상수 `Σ_k w_k·ρ_k`). 본 설계는 `w_k=ρ_k`이므로 동치 대상은 **ρ-가중 부족분
  `Σ_k ρ_k·(ρ_k − cov_k)`**, 상수는 `Σ_k ρ_k²`. (§11 발표 논리의 "가중 갭"이 이것)

## 7. 제약조건

### 하드 제약 (반드시 만족)

```
(C1) 분반 택1     :  Σ_{s∈S(c)} y_{c,s} ≤ 1                         ∀ c ∈ C
(C2) 학점 범위    :  B_lo ≤ Σ_{c,s} cr_c · y_{c,s} ≤ B_hi
(C3) 시간 충돌    :  Σ_{(c,s): t ∈ slots(c,s)} y_{c,s} ≤ 1          ∀ t ∈ T
(C4) 적합도 캡    :  cov_k ≤ ρ_{J,k}   및   cov_k ≤ attained_k       ∀ k ∈ K
(C5) 졸업 보너스 캡:  grad_g ≤ need_g
                     grad_g ≤ Σ_{c: a_c=g} cr_c · x_c               ∀ g ∈ G
```

- **(C1)** 같은 과목을 두 분반 동시 수강 금지.
- **(C2)** 이번 학기 총 학점이 등록 가능 범위 안.
- **(C3) = 시간 충돌의 핵심.** 한 시간 슬롯(예: 월요일 3교시)에 분반은 최대 1개 →
  추천 결과는 자동으로 시간이 안 겹친다.
- **(C4)** 6장의 적합도 캡 구현. **(C5)** 졸업 보너스 캡(필요 이상 채우면 보너스 정체).
- **왜 등식이 아니라 상한 2개만 거는가:** `cov_k = min(attained_k, ρ_k)`를 등식으로 강제하려면
  이진변수가 필요하지만, 목적함수가 `cov_k`를 **최대화**(계수 `ρ_k ≥ 0`)하므로 상한 `cov_k ≤ ρ_k`,
  `cov_k ≤ attained_k` 두 개만 걸어도 솔버가 `cov_k`를 자동으로 min까지 끌어올린다(big-M·이진변수
  불필요). `grad_g`도 동일(계수 `λ/need_g > 0`).
- **경계 조건:** `ρ_k = 0`인 역량은 캡 `cov_k ≤ ρ_k = 0`과 `cov_k ≥ 0`으로 `cov_k = 0` 고정 —
  목적 기여가 0이라 **추천 리포트의 의미 지표로 쓰지 말 것.** (본 시스템은 `역량_taxonomy_근거.md`상
  모든 직무에서 `ρ_k > 0`을 보장하므로 실무상 문제없음.) `need_g = 0`(이미 충족된 영역)은 졸업 항
  합산에서 제외.

### 후보 사전 필터 (집합 정의 단계에서 처리 → 제약 불필요)

- **개설 학기**: `C`를 `term` 개설 과목으로만 구성.
- **이미 수강**: 학생 기수강 과목은 후보 `C`에서 제외.

### 소프트 제약 (강제 X — 영준 피드백 반영)

실제로는 3학년이 4학년 수업을 듣고 선수과목도 강하게 강제되지 않으므로, **하드 제약으로
두지 않는다.**

- **선수과목 / 학년 제한**: 기본은 **무시**. 필요 시 목적함수에 작은 페널티 항
  `− μ · (선수 미충족·학년 초과 분반 선택 수)`로만 약하게 반영(옵션). `course.allowed_years`는
  대부분 `1,2,3,4`로 열려 있어 실효 제약이 거의 없다.

## 8. 시간 충돌 제약 (C3) 동작 예시

`데이터사이언스`(140316)는 두 분반:
- 1반: `수89,금9` → slots = {수8, 수9, 금9}
- 2반: `목789` → slots = {목7, 목8, 목9}

`시스템분석`(140715) 1반: `월91011` → slots = {월9, 월10, 월11}

이 셋은 슬롯이 겹치지 않으므로 (C3) 위배 없이 동시 추천 가능. 만약 어떤 과목 분반이
`수89`를 점유하면, 데이터사이언스 1반(`수89` 포함)과는 같은 슬롯 `수8/수9`에서
`Σ y ≤ 1`에 걸려 **둘 중 하나만** 선택된다.

## 9. PuLP 구현 스케치

`requirements.txt`에 `pulp>=2.7.0` 이미 포함. MILP로 풀린다.

```python
import pulp

prob = pulp.LpProblem("course_fit", pulp.LpMaximize)

# 결정변수: 분반
y = {(c, s): pulp.LpVariable(f"y_{c}_{s}", cat="Binary") for (c, s) in sections}
x = {c: pulp.lpSum(y[c, s] for s in S[c]) for c in courses}                 # 과목 수강(파생)
attained = {k: sigma[k] + pulp.lpSum(w[c][k] * x[c] for c in courses) for k in K}

cov  = {k: pulp.LpVariable(f"cov_{k}",  lowBound=0) for k in K}
grad = {g: pulp.LpVariable(f"grad_{g}", lowBound=0) for g in G}

# 목적함수: 직무 적합 + λ·정규화 졸업 진척 (need_g>0인 영역만)
prob += (pulp.lpSum(rho[J][k] * cov[k] for k in K)
         + LAMBDA * pulp.lpSum(grad[g] / need[g] for g in G if need[g] > 0))

# (C4) 적합도 캡
for k in K:
    prob += cov[k] <= rho[J][k]
    prob += cov[k] <= attained[k]

# (C5) 졸업 보너스 캡
for g in G:
    prob += grad[g] <= need[g]
    prob += grad[g] <= pulp.lpSum(cr[c] * x[c] for c in courses if area[c] == g)

# (C1) 분반 택1
for c in courses:
    prob += pulp.lpSum(y[c, s] for s in S[c]) <= 1

# (C2) 학점 범위
total_credit = pulp.lpSum(cr[c] * y[c, s] for (c, s) in sections)
prob += total_credit <= B_hi
prob += total_credit >= B_lo

# (C3) 시간 충돌: 슬롯당 분반 ≤ 1
for t in T:
    prob += pulp.lpSum(y[c, s] for (c, s) in sections if t in slots[(c, s)]) <= 1

prob.solve()
chosen = [(c, s) for (c, s) in sections if pulp.value(y[c, s]) == 1]
```

## 부록 A. 확정 사항 / 미해결

- **`ρ_{J,k}`(직무 요구수준)의 기준 = 직무 기준(확정).** 교수님 피드백("직무 기준 vs 사람
  기준 통일")에 대해 **직무 기준**으로 통일한다. 즉 `job_competency.required_level`은 *그 직무
  자체가 요구하는 수준*(채용공고에서 도출)으로 정의하며, 특정 현직자/학생 개인의 보유 수준이
  아니다. `job_competency.csv` 생성(이슈 #10)도 이 기준을 따른다.
- `B_lo, B_hi` 기본값(예: 12~21)과 `λ, μ` 초기값은 1단계 구현 후 실측으로 튜닝.
