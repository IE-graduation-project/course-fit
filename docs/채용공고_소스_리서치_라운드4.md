> 작성: 2026-05-10 (유영준)
> 범위: 라운드 1~3에서 못 잡은 한국 기업 50+ 곳을 5개 카테고리로 분할 검증
> 카테고리: A 메이저 IT 플랫폼 / B 대기업 그룹 / C 금융권 / D 게임사 / E AI·유니콘·바이오

## TL;DR

- **GreetingHR ATS가 한국 IT 채용의 사실상 표준** 확정 — 단일 어댑터로 **12사 동시 수집** 가능
- **42dot Ashby 공식 API** = 자율주행 AI 118 jobs (descriptionHtml 풀 페이로드)
- **SaaS 표준 어댑터 4개**가 ROI 최대 — Greeting / Ashby / SmartRecruiters / recruiter.co.kr
- 한국 게임사 12곳 모두 **Greenhouse·Lever 미사용** (`gravity` 슬러그는 헝가리 광고사 함정)
- 대기업 자체 careers는 대부분 자체 SPA — **자체 fetcher 비추**, 사람인/잡알리오 OpenAPI로 우회 권장
- **새로 검증된 즉시 가능 회사 17~20곳** (라운드 1~3의 7곳에 추가)

## 게임체인저: SaaS 어댑터 패턴

라운드 4의 가장 큰 발견은 **회사별 fetcher가 아닌 ATS별 어댑터**가 ROI 최대라는 점. 한 어댑터로 다수 회사를 동시 처리 가능.
