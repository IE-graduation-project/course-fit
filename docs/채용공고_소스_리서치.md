## Tier 1 — 즉시 채택 (검증 완료, 무인증 GET, 약 600+ 공고)

`data/job_posting.csv`의 첫 batch는 이 5개 소스로 채울 것을 권장.

### 1.1 Greenhouse Job Board API (3사)

무인증 GET, hard rate limit 없음, 공식 문서가 "publicly accessible for client-side applications" 명시.

| 회사 | 공고 수 | 한국어 본문 | 산데공 직군 | 경영 직군 |
|---|---|---|---|---|
| **크래프톤** | 57 | **풍부** (요구역량/우대 원문) | AI Frontier·Server·Data | HR·Business·기획 |
| **쿠팡** | 387 | 한·영 혼재 | DS·Data Eng·Logistics | PMO·BizOps |
| **당근** | 45 | **풍부** | Backend·Data Platform | Local Jobs PM·Content |
| (보조) Naver Vietnam | 27 | 영문 | Cloud·Search | - |
| (보조) Seoul Robotics | 7 | 영문 | LiDAR/AV | - |

**검증된 호출**:
```bash
curl -s 'https://boards-api.greenhouse.io/v1/boards/krafton/jobs?content=true'
curl -s 'https://boards-api.greenhouse.io/v1/boards/coupang/jobs?content=true'
curl -s 'https://boards-api.greenhouse.io/v1/boards/daangn/jobs?content=true'
curl -s 'https://boards-api.greenhouse.io/v1/boards/navervietnam/jobs?content=true'
curl -s 'https://boards-api.greenhouse.io/v1/boards/seoulrobotics/jobs?content=true'
```

**응답 필드** (`content=true` 시 본문 포함):
- `id`, `title`, `absolute_url`, `updated_at`, `location.name`
- `departments[]`, `offices[]`, `metadata[]` (Job Level 등)
- `content` — HTML 본문 (요구역량/우대사항 원문)

→ `job_posting.csv` 매핑이 깔끔: `posting_url=absolute_url`, `raw_text=BeautifulSoup(content).get_text()`, `source="Greenhouse:{slug}"`, `crawled_at=now().isoformat()`.

### 1.2 네이버 자체 JSON

**검증된 호출**:
```bash
curl -s 'https://recruit.navercorp.com/rcrt/loadJobList.do'
# 응답 예: {"result":"Y","list":[{"annoId":30004817,"sysCompanyCdNm":"NAVER","annoSubject":"[NAVER] HR 운영 지원 (보훈특별/계약)",...}]}
```

- robots.txt에 채용 경로 명시 disallow 없음
- NAVER / NAVER Cloud / WEBTOON 그룹사 분리
- 본문은 `annoId`로 상세 페이지 추가 호출 필요 (`/rcrt/loadAnnoView.do?annoId=...` 류)
- ToS 자동수집 일반 조항 → User-Agent 표기·저빈도(1회/일) 권장

### 1.3 카카오 자체 JSON

**검증된 호출**:
```bash
curl -s 'https://careers.kakao.com/public/api/job-list?skillSet=&part=&company=&keyword=&employeeType=&page=1'
# 응답 예: {"jobList":[{"jobOfferTitle":"Multimodal LLM Research Engineer (경력)",...}]}
```

- 한국어 본문 매우 풍부, 우대/요구역량 정형 4-section
- 카테고리: Tech / Staff / Business / Design
- 카카오뱅크/카카오페이/카카오모빌리티는 별도 GreetingHR 도메인 (Phase 2)

## `data/job_posting.csv` 매핑 전략

박소연님 스펙: `job_id, source, posting_url, raw_text, crawled_at`

### `source` 명명 규칙 제안

```
Greenhouse:{slug}      예: Greenhouse:krafton, Greenhouse:coupang
NaverCareers           recruit.navercorp.com 자체
KakaoCareers           careers.kakao.com 자체
Saramin:OpenAPI        사람인 API
WorkNet:Recruit        워크넷 채용정보 API
WorkNet:GovJobs        워크넷 정부지원일자리 API
ALIO                   잡알리오
Jumpit                 점핏 HTML
Linkareer              링커리어 HTML
Greeting:{slug}        예: Greeting:kurlym, Greeting:kakaopay
Toss / Yanolja / Woowahan / SK   회사별 자체
Manual:{program}       예: Manual:SoftwareMaestro
```

### `job_id` 매핑 전략 (LLM 매핑 단계와 분담)

크롤러가 떨어뜨리는 `job_id`는 **placeholder 또는 빈 값**으로 두고, `mapping/map_postings.py`에서 LLM이 raw_text + 직군 태그 → `job.csv` 의 job_id로 매핑.

대안: Greenhouse `departments[]`, 사람인 `job_cd`, 워크넷 KECO 코드를 **힌트**로 같이 떨어뜨리는 컬럼 제안 (스키마 변경 필요 시 박소연님과 상의).

### `raw_text` 추출 가이드

- Greenhouse `content` HTML → BeautifulSoup `get_text(separator='\n', strip=True)`
- 네이버/카카오 → 상세 페이지 추가 호출 후 본문 div 추출
- 사람인 API → 메타 + `keyword-code` (요구역량 본문 부재) → 추후 LLM 매핑 시 한계 인지
- CSV 저장: `csv.QUOTE_ALL` 또는 `pandas.to_csv(index=False, encoding='utf-8')`

### `crawled_at`

```python
from datetime import datetime, timezone
crawled_at = datetime.now(timezone.utc).isoformat()  # 2026-05-10T03:25:11.123456+00:00
```

## 박소연님 결정 필요 항목

1. **`job_posting.csv`에 직군 힌트 컬럼 추가 여부** — Greenhouse `departments[]`, 사람인 `job_cd`, KECO 코드 등 LLM 매핑에 유용한 raw 메타. 스키마 변경 필요.
2. **`source` 명명 규칙 합의** (위 제안 vs 다른 컨벤션)
3. **`raw_text`에 회사명·지역·경력·마감일 같은 메타데이터를 텍스트로 인라인할지 vs 별도 컬럼으로 뺄지** — 현재 스펙은 `raw_text` 한 덩어리. LLM 매핑이 메타와 본문 같이 보면 정확도 ↑
4. **OpenAPI 신청 분담** — 잡알리오/워크넷/사람인/원티드/잡코리아 5종, 박소연·유영준 분담
5. **법적 리스크 surface 시점** — 교수 미팅에서 대법원 판례 + "공식 API 트랙으로만 간다" 명시 필요
6. **일일 fetch 정기화** — Phase 1은 1회 batch, Phase 2부터는 cron으로 일일 갱신할지

### 박소연님과 합의 필요한 항목 (업데이트)

1. **사업자번호 처리** — 잡코리아·원티드 신청에 학교 사업자번호가 필요. 박소연님 또는 지도교수님께 학교 행정실 연결 요청 필요. 그 사이엔 `잡알리오 + 사람인 + Greenhouse 5사 + 네이버/카카오 자체 JSON`만으로 PoC 진행 가능.
2. **워크넷 데이터 포기 또는 우회** — 학부 졸프 단계에서 워크넷은 사실상 차단 상태. 대안:
   - 데이터 양으로 보면 사람인 OpenAPI가 워크넷이 cover하는 영역(공공·중견기업)도 어느 정도 포함
   - 잡알리오로 공공기관·금융공기업은 cover 가능
   - 워크넷 KECO 직종 코드 자체는 별도로 다운로드 가능한 fileData 형식으로 (data.go.kr/data/15119096) 제공 → 직무 분류 매핑에만 활용
3. **사람인 학술 사용 메일 문의** — `api@saramin.co.kr`에 학술 비영리 prototype 사용 가능 여부 + 출처 표기 형식 + DB 캐시 가능 여부 사전 메일 문의 권장 (라운드 1에서 명시).
