## 2. 화면 셋

### 2.1 `/` 랜딩
한 문장 + 시작 버튼 + 원칙 3개. 스크롤 없이 끝난다.
「부족한 것부터 · 겹치지 않게 · 졸업도 같이」 — 우리 시스템이 남과 다른 지점 셋.

### 2.2 `/start` 입력 — 대화형
> 소연님(6/10): *"성적표를 넣기 과정을 약간 채팅처럼 재밌게 표현하거나"*

3번 물어보고 끝난다.

1. **성적표 붙여넣기** — 「성적표 어디서 가져와요?」 를 접이식으로 붙여서
   *클래스넷 → 성적정보 → 전체성적조회 → Ctrl+A/C → 여기 Ctrl+V* 4단계를 화면 안에서 알려준다.
   («샘플로 먼저 볼래요» 버튼으로 성적표 없이도 끝까지 볼 수 있다 — 발표 시연용이기도 하다.)
2. **직무 6개** — 아이콘 카드. 글씨는 직무명뿐.
3. **성향 3개** — ε 을 「역량 우선 / 균형 / 졸업 우선」로만 노출. 숫자 0.3 은 안 보여준다.

**ε 을 왜 숨겼나**: ε=0.3 이 뭔지는 우리가 아는 것이고 학생은 모른다.
"뭘 더 챙길까"라는 질문으로 바꾸면 설명 없이 고를 수 있다. (결과 화면에서는 작게 노출 — 발표·디버깅용)

### 2.3 `/result` 결과 — 정적 한 화면
> 소연님(6/10): *"시간표 추천은 다른 화면에 정적으로 보여주는게 좋을거 같아요"*

- **시간표 그리드가 주인공.** 월~금 × 교시. 과목마다 고정 색, 연강은 한 덩어리.
- 위에 배지 4개 — `총 학점` `과목 수` `✓시간 충돌 0` `✓기수강 제외` `✓선수과목 충족`.
  우리 시스템의 hard 제약이 곧 **학생에게 파는 가치**라서 결과 맨 위에 뒀다.
- 오른쪽 **역량 진단** — 막대=σ(내가 쌓은 것), 눈금=ρ(직무 요구), 빗금=gap.
  모자란 축만 진하게, 충족은 흐리게 + 「충족」.
- 아래 **졸업까지 남은 것** — 영역별 남은 학점.
- 아래 **왜 이 과목들일까요?** — 과목 카드마다 `Score` 의 축별 분해를 누적 막대로.
- **성향 토글을 결과 화면에도** 뒀다. 누르면 즉시 다른 시간표. 이게 「왜 이렇게 추천했냐」에 대한
  가장 빠른 답이라 챗봇보다 먼저 넣었다.
- 「어떻게 계산했나요?」를 누르면 σ→gap→Score→ILP 사슬을 한 문단으로. **ρ와 σ가 같은 척도가 아니라는
  한계도 그 안에 적어뒀다** (`docs/시스템_한계.md` §1과 동기화).

## 3. 규칙 몇 개

**색**: 역량 10축에 고정 색을 줬다(`web/lib/competency.ts`). 진단 막대의 라벨 점과 과목 카드의
근거 막대가 같은 색이라, 글씨를 안 읽어도 *"데이터베이스가 모자라다 → 이 과목이 그 색을 크게 물었다"* 가 보인다.
소연님이 말한 「글씨 최대한 없이」를 이 방식으로 풀었다.

**글씨**: 숫자는 전부 tabular(표에서 안 흔들림). 한국어라 letter-spacing 0, 어절 단위 줄바꿈.
Pretendard.

**다크모드 안 한다.** 발표·시연 환경이 밝고, 두 벌 유지할 이유가 없다.

**모바일**: 돌아가긴 하는데 시간표 그리드가 좁다. 데스크톱 우선으로 뒀다 (§5 참고).

## 5. 소연님께 물어볼 것

1. **백엔드 API, 누가 언제?**
   지금 HTTP 레이어가 아예 없다. `docs/API_계약.md` 대로 FastAPI 로 감싸면 되고 계산 로직은 손댈 게 없다.
   소연님이 해주시면 제가 붙이고, 시간이 안 되면 제가 껍데기만 짜고 리뷰받겠습니다.

2. **σ 포화 문제 — 이거 발표에서 맞을 것 같다.**
   제 성적표(45과목)로 돌리니 σ 가 10축 중 8축에서 0.9 를 넘고 gap 이 0.15 근처로 눌린다.
   4학년일수록 "다 충족" 으로 보여서 **진단 화면이 심심하고 변별력도 떨어진다.**
   α(1.5) 를 낮추거나 σ 를 학년 대비 상대화하는 걸 생각해볼 시점 같습니다. 로직 쪽이라 의견 듣고 싶습니다.

3. **직무 6개로 충분한가?** 경영·산데공 대상이면 컨설턴트·HR·SCM 쪽이 빠져 있다.

4. **모바일 어디까지?** 지금은 데스크톱 우선. 발표 시연이 노트북이면 이대로 두고
   학기 말 실사용을 노리면 시간표 그리드를 세로형으로 다시 짜야 한다.

5. **화면 구성 — 6월 안(한 화면 모핑) vs 8월 안(3화면)** 중 발표에 뭐가 나아 보이시는지.
   스크린샷은 `docs/screenshots/` (8월) 과 6월 브랜치에 각각 있습니다.

6. **결과에서 과목을 빼고 다시 풀기** (「이 과목 말고 다른 거」) 를 넣을지.
   ILP 재호출이라 백엔드가 붙으면 어렵지 않은데, 범위 문제라 같이 정하면 좋겠습니다.
