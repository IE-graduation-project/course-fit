# 졸업요건 파싱 노트

## 1. MVP에서 모델링하는 규칙

ILP의 hard constraint로 처리.

- 영역별 최소 학점
- 영역별 상한 학점 (교양총합)
- 강제 선택 과목 (`is_major_required = 1`)
- 선수과목 (`prerequisites`)
- 학과별·입학년도별 요건 분리
- 총 졸업 학점 132

## 2. MVP에서 무시하는 규칙

Soft warning 후처리로 안내 (`recommender/post_check.py`).

- 4세트 중 2세트 (산데공은 항목 5-② 적용으로 직접 무관)

- 공통교양 7개 영역 중 6개 영역 분산
- 특성화교양 그룹 중 1과목 선택

### 공통
- 영어 인증, 설계 최소요구학점 (외부 인증)
- 졸업논문 (시간표 무관)
- 프로그램 이수체계 준수

## 4. 선수과목 (이수계통도 실선만)

**산데공 (2026)**
| 후속 | 선수 |
|------|------|
| 의사결정2 (140420) | 의사결정1 (140318) |
| 데이터기반최적화 (140526) | 의사결정2 (140420) |
| 시스템설계 (140815) | 시스템분석 (140715) |
| 시계열분석 (140724) | 선형통계모형 (140625) |
| 다변량통계분석 (140725) | 선형통계모형 (140625) |
| 바이오헬스응용 (140834) | 기계학습1 (140528) |
| 비정형데이터분석 (140832) | 기계학습1 (140528) |

**경영 (2022~)**: 명시적 선수 없음 (이수계통도 모두 점선)

**Transitive closure**: 직접 선수만 명시. 학생이 의사결정1 미수강 → 의사결정2 못 듦 → 데이터기반최적화도 자연스럽게 제외됨.

**권고 관계 (점선)**: prerequisites에 반영하지 않음. 향후 score 페널티 또는 soft warning으로 확장 가능.

## 6. 교양총합 합산 대상

ILP 코드 상수:
```python
EDUCATION_AREAS = ['교양필수', '특성화교양', '공통교양']
```

SW데이터활용역량은 교양에 포함 안 됨 (별도 영역).

## 7. course 테이블 향후 수정 예정

`liberal_area TEXT` 컬럼 추가 (공통교양 7영역 분류용).
- 공통교양 아닌 과목은 NULL
- Day 2 교양 과목 크롤링 시 정확한 영역명 확정
- Soft warning에서 영역 분산 검사에 사용

## 8. 발표 방어 논리

> "졸업요건의 영역별 최소·최대 학점 제약, 강제 선택 과목, 선수과목 관계를 ILP의 hard constraint로 1차 모델링했다. 분야별 분배·영역 분산·그룹 내 선택 규칙은 모델 복잡도와 본 연구의 핵심 기여(직무 적합도 추천) 집중을 위해 향후 과제로 분류하고 soft warning으로 안내한다."

## 9. 향후 확장 우선순위

1. MSC 분야별 분배 (산데공) — `msc_subarea` 컬럼 이미 존재
2. 공통교양 7중 6 영역 분산 — `liberal_area` 컬럼 추가 후 가능
3. 특성화교양 그룹 중 1과목 — set indicator 변수 추가
4. 권고 선수과목 — score 함수 페널티
